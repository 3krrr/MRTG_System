클래스룸 열기

다운로드한 config.js는 압축을 푼 web 폴더의 config.js와 교체하세요. GitHub에는 web 폴더 안의 파일들을 기존 사이트 파일 위치에 올립니다. 다른 PC와 휴대폰은 GitHub 사이트 주소로 접속합니다.

요청한 간단 모드입니다. 계정 비밀번호는 평문으로 저장되고 역할별 화면은 HTML에서 구분합니다. HTML을 변경하거나 공개 API를 직접 호출하는 사용자의 접근을 DB가 막는 구조는 아닙니다.
