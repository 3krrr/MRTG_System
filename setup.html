사이트 연결 설정

기존 연결은 config.js를 그대로 사용합니다. SQL 31까지 적용한 프로젝트는 SQL 32를 추가 실행한 뒤 사이트 파일을 교체하세요. SQL 27까지만 적용했다면 28~32 통합 업데이트를 사용합니다. 비어 있는 새 프로젝트는 SQL 1~32 전체 설치 파일을 사용하세요. 자세한 순서는 압축파일의 설치와 사용 안내.html에 있습니다.

Supabase 프로젝트의 Connect 또는 Settings → API Keys에서 확인합니다. Secret / service_role 키는 넣지 마세요.

연결할 프로젝트 정보를 입력해 주세요.

첫 관리자 생성과 비밀번호 복구는 Supabase SQL Editor에서만 가능합니다. 배포 묶음의 관리자_SQL_비공개 폴더를 확인하세요.

클래스룸 열기

새 프로젝트에서 내려받은 config.js는 GitHub의 index.html 옆에 올립니다. 기존 프로젝트는 기존 config.js와 CNAME을 유지하세요.
