서버 없이 연결하기

기존 사이트를 업데이트한다면 저장된 설정을 그대로 사용하세요. SQL08·SQL09·SQL10 중 하나를 이미 설치했다면 새 SQL이 필요하지 않습니다. 처음 설치하거나 더 오래된 저장 구조를 사용한다면 압축파일의 11_v2_7_0_update.sql을 Supabase → SQL Editor → New query에서 추가 실행하세요. 기존 자료를 삭제하지 마세요.

Supabase의 프로젝트 Connect 또는 Settings → API Keys에서 확인합니다. Secret / service_role 키는 넣지 마세요.

연결할 프로젝트 정보를 입력해 주세요.

클래스룸 열기

다운로드한 config.js는 GitHub에서 현재 index.html 옆에 있는 config.js와 교체하세요. GitHub에는 GitHub에_올릴_파일 폴더 안의 파일들을 기존 사이트 파일 위치에 올립니다. 다른 PC와 휴대폰은 GitHub 사이트 주소로 접속합니다.

요청한 간단 모드입니다. 계정 비밀번호는 평문으로 저장되고 역할별 화면은 HTML에서 구분합니다. HTML을 변경하거나 공개 API를 직접 호출하는 사용자의 접근을 DB가 막는 구조는 아닙니다.
