수업 준비강의계획과 자료수업 당일출결과 학부모 안내수업 후기록·테스트·레포트

담당 강좌의 업무를 기준으로 안내합니다. 개별 권한과 공개범위에 따라 보이는 항목은 다를 수 있습니다.

01 · 처음 사용

로그인과 내 정보

내 이름 · 개인설정

  1. 안내받은 클래스룸 아이디와 비밀번호로 로그인합니다. 기본 비밀번호가 1234라면 새 비밀번호를 두 번 입력해 변경합니다.
  2. 오른쪽 위 내 이름 또는 개인설정을 열고 내 전화번호를 저장합니다.
  3. 개인 타임넷 계정에 본인 계정을 넣고 연결 확인하고 저장을 누릅니다.
  4. 엠스위치 연동에 본인 계정을 넣고 저장 · 연동하기를 누릅니다.
타임넷·엠스위치에서 비밀번호를 바꿨다면 클래스룸 개인설정에도 새 비밀번호를 저장하세요.

주의사항이 보일 때

상단 주의 N건을 열어 해당 항목의 해결방법과 바로 이동을 이용합니다. 비밀번호 변경이나 본인 확인이 필요하면 해당 서비스에서 먼저 완료한 뒤 클래스룸에서 다시 연결합니다.

02 · 수업 준비

담당 강좌 열기

강좌관리 → 강좌 설정

  1. 목록에서 담당 반을 누릅니다. 반 이름 아래에 설정과 수업 기록이 펼쳐집니다.
  2. 강좌 정보 수정에서 일정·요일·시각·강의실을 확인합니다. 강의실은 숫자 3자리로 입력하며 요일마다 다르게 지정할 수 있습니다.
  3. 공개범위에서 학생·학부모에게 보여 줄 수업·성적·영상·자료 항목을 확인합니다.
  4. 일정을 바꿨다면 저장 후 표시된 날짜와 강의실을 다시 확인합니다.
강좌는 반 전체, 수업 기록은 날짜별 한 회차입니다. 새 수업은 반 안에서 추가합니다.

새 강좌를 만들 때

강좌 개설에서 강좌명·소속·기간·요일·시간·강의실을 입력합니다. 소속이 여러 개이면 해당 강좌의 소속을 선택합니다. 담당강사·부담임과 공개범위를 확인하고 저장하세요.

03 · 반 안내

로그인 화면에 반 공지 띄우기

강좌 설정 → 담당 반 → 반 공지

  1. 반 공지 → 공지 추가를 누릅니다.
  2. 제목·내용을 입력하고 노출 종료 날짜와 시각을 지정합니다. 현재 이후부터 종강 시각 사이에서 선택하세요.
  3. 저장을 누르면 해당 반 학생·학부모가 로그인할 때 공지를 확인합니다. 확인 한 번으로 닫으며, 노출 기간에는 다음 접속 때 다시 보일 수 있습니다.
  4. 내용이나 기한을 바꾸려면 수정, 바로 끝내려면 노출 끄기를 누릅니다. 기한이 지나거나 종강하면 노출이 끝납니다.
긴급한 내용의 경우 사용하시길 바랍니다.

04 · 수업 준비

강의계획서 작성과 서식

강좌 설정 → 담당 반 → 강의계획 → 강의계획 수정

  1. 비고 사용을 선택합니다. 비고가 필요하지 않으면 끕니다. 비고가 모두 빈칸이면 저장할 때 자동으로 꺼집니다.
  2. 교재나 분야를 나누어 쓰려면 여러 열 사용을 켜고 열 추가로 필요한 진도 열을 추가합니다. 진도 열은 최대 8개입니다.
  3. 진도 열이 하나면 제목은 수업/진도입니다. 두 개 이상이면 각 열에 교재명이나 범주 이름을 입력합니다. 제목이 빈 열은 저장할 수 없습니다.
  4. 날짜·회차에 맞춰 계획을 입력합니다. 내용이 길어지면 입력칸이 아래로 늘어납니다. 필요 없는 열은 해당 열의 삭제 버튼으로 정리합니다.
  5. 서식 탭에서 전체 회차 또는 선택 회차를 고릅니다. 일부만 바꾸려면 왼쪽의 회차를 체크하세요. 좌정렬 / 중앙정렬 / 우정렬, 굵게, 글자색을 지정한 뒤 적용을 누릅니다.
  6. 저장을 누른 뒤 강의계획을 다시 열어 열 이름·진도·비고·서식을 확인합니다.

학생·학부모에게 보이는 화면

PC에서는 최대 8개 진도 열을 한 화면에서 봅니다. 휴대폰에서는 위쪽 교재·범주 이름을 눌러 해당 진도만 확인하며, 비고는 표시하지 않습니다.

강의계획은 예정 진도입니다. 실제 진행 내용과 출결·성적은 수업 기록에서 저장합니다.

05 · 학생 준비

학생 등록과 계정 확인

학생관리 → 학생 관리 / 학생 학부모 계정 관리

  1. 학생 관리에서 학생관리 버튼을 열고 등록할 강좌를 선택합니다.
  2. 타임넷 명단에서 이름을 찾고 학교·학년·원생번호를 함께 확인합니다. 필요할 때 타임넷 학생 불러오기로 갱신합니다.
  3. 등록할 학생과 학부모 연결을 확인합니다. 학부모 계정 자동 생성과 기본 비밀번호 사용하기는 기본 체크되어 있습니다.
  4. 저장 후 학생 학부모 계정 관리의 학생·학부모 탭에서 발급 아이디와 연결된 가족을 확인합니다.
이미 계정이 있는 원생은 기존 계정을 사용합니다. 동명이인 아이디에 숫자가 붙으면 숫자까지 안내하세요. 본인이 바꾼 비밀번호를 임의로 초기화하지 않습니다.
목차로 ↑
06 · 학생 준비

학부모 연락처 맞추기

학생관리 → 학부모 전화번호 관리

  1. 학생·학부모를 검색하고 클래스룸·타임넷·엠스위치 번호를 비교합니다.
  2. 오래된 정보라면 즉시 갱신 후 다시 확인합니다.
  3. 서로 다른 번호가 있으면 실제 보호자 번호와 엠스위치의 학생을 확인한 뒤 수정·저장합니다.
  4. 저장 결과와 최종 번호를 확인합니다. 직접 해결되지 않으면 엠스위치에서 수정하고 다시 갱신합니다.
문자는 실제 수신번호, 앱 알림은 연결된 학부모 계정과 기기로 전달됩니다. 연락처와 가족 연결을 함께 확인하세요.
목차로 ↑
07 · 학생 준비

앱 설치 안내 보내기

공통관리 → 앱푸시 보내기 → 앱설치 알림 문자 발송

  1. 담당 학부모 중 앱 알림 준비가 필요한 대상을 선택합니다. 이미 앱 알림이 가능한 학부모는 안내 대상에서 제외됩니다.
  2. 이름이나 행을 눌러 실제 메시지의 아이디·비밀번호 안내를 확인합니다.
  3. 체크한 대상과 문구를 확인하고 발송합니다.
  4. 결과를 확인하고 필요하면 통신내역 → 자세히에서 대상별 상태를 봅니다.
문구를 수정할 때 <$아이디>와 <$비밀번호>는 남겨 두세요. 본인이 변경한 비밀번호는 “본인이 설정한 비밀번호”로 안내됩니다. 같은 학부모에게 설치 안내는 주 1회 정도로 안내하세요.

08 · 수업 당일

실시간 출결 저장과 안내

출결관리 → 실시간 출결

  1. 반과 수업 날짜를 확인합니다.
  2. 학생별 등원 / 미등원 / 결석 / 지각을 선택합니다. 같은 버튼을 다시 누르면 선택이 해제됩니다.
  3. 등원 시각을 확인하고 ▲·▼로 1분씩 조정합니다. 이미 등원 안내가 접수된 시각은 잠깁니다.
  4. 발송 버튼 위의 상태별 선택 인원과 수신 대상을 확인합니다.
  5. 출석부 저장 후 학부모 안내 발송을 누르고 저장·발송 결과를 확인합니다.
모바일 전체 출석은 등원 상태를 한꺼번에 선택합니다. 저장·발송은 버튼을 눌러 별도로 진행합니다. 결과가 불분명하면 먼저 통신내역을 확인하세요.
목차로 ↑
09 · 수업 당일

출석부 확인과 수정

출결관리 → 출석부

  1. 반과 조회 기간을 선택합니다. 이번 달 수업 등 필요한 범위를 고릅니다.
  2. 날짜별 출결과 사유를 확인하고 필요한 항목을 수정·저장합니다.
  3. 출력할 때도 선택한 반·기간을 먼저 확인합니다. 조회 범위는 다음 접속에도 유지됩니다.
실시간 출결·출석부·수업 기록의 출결은 같은 기준을 사용합니다. 다른 날짜로 바꿨다면 그 날짜의 학생별 상태를 다시 확인하세요.

다른 요일의 쌍둥이반에 등원했다면

실제 등원 시각과 원래 반의 대응 수업일을 함께 확인합니다. 대응이 애매하면 화면에 안내된 반·날짜를 확인한 뒤 처리하세요. 학생 한 명의 여러 반 출결은 학생종합검색에서 봅니다.

10 · 수업 후

수업 기록 추가

강좌관리 → 강좌 설정 → 담당 반 → 수업 기록 추가

  1. 수업일·회차·제목을 확인합니다. 이미 있는 회차는 기존 기록을 열어 수정합니다.
  2. 오늘의 진도, 숙제 안내, 공지를 입력합니다. 해당 회차의 강의계획이 있으면 비어 있는 진도에 가져옵니다.
  3. 추가자료·영상·테스트를 넣고 학생별 출결·과제·코멘트를 입력합니다.
  4. 온라인으로 과제를 받을 수업만 온라인 과제 제출 허용을 체크합니다.
  5. 저장 후 해당 기록을 다시 열어 날짜와 내용을 확인합니다.
진도·숙제·공지와 학생별 코멘트는 입력한 내용에 맞춰 아래로 늘어납니다. 모바일은 학생의 자세히를 펼쳐 입력합니다.

학생·학부모에게 알릴 때

  1. 수업의 레포트 발송을 엽니다.
  2. 학부모·학생 목록에서 날짜별 출결과 체크 상태를 확인합니다.
  3. 보낼 대상만 체크하고 발송합니다. 결석한 학생도 체크되어 있으면 대상에 포함됩니다.
목차로 ↑
11 · 수업 후

여러 테스트와 점수 입력

수업 기록 추가 · 수정 → 이번 수업 테스트

  1. 테스트 추가로 테스트를 넣거나 저장한 시험지를 연결합니다.
  2. 각 테스트의 제목·만점을 확인하고 필요한 설정을 지정합니다.
  3. 테스트가 여러 개이면 학생별 수업 기록 위에서 입력할 테스트 이름을 누릅니다. 선택한 시험의 점수 칸이 표시됩니다.
  4. 학생별 점수를 입력합니다. 다른 테스트 이름을 눌러 전환해도 입력값은 유지됩니다. 미응시·미입력과 실제 0점을 구분하고 만점 이내로 입력합니다.
  5. 수업 · 학생 기록 저장을 누릅니다. 모바일은 저장입니다. 모든 테스트의 점수가 함께 저장되며, 다시 열어 결과를 확인합니다.
테스트가 하나이면 선택 버튼 없이 바로 점수를 입력합니다. 여러 테스트는 이름을 바꿔 가며 한 시험씩 집중해서 입력하세요.

잘못 추가한 테스트

삭제 후 수업 기록을 저장합니다. 저장 전에는 삭제 취소로 되돌릴 수 있습니다. 저장된 점수와 쌍둥이반의 연결 테스트에도 영향을 줄 수 있으므로 삭제 대상을 확인하세요.

평균 표시 설정

평균조작에서 정수 비율 또는 고정 평균을 지정하고 적용 → 수업 기록 저장을 누릅니다. 직원 화면의 기본은 실제 평균이며, 필요한 화면에서 조정 평균 보기로 확인합니다.

12 · 시험·클리닉

미탐존 시험지 만들기부터 클리닉까지

미탐존 시험지 관리 → 시험지 만들기

1. 교재와 문항으로 시험지 만들기

  1. 개인설정 → 엠스위치 연동에서 본인 계정을 연결합니다. 연결 확인을 완료한 계정으로 이용합니다. 연결 안내가 나오면 계정 연결 확인을 누릅니다.
  2. 미탐존 시험지 관리 → 시험지 만들기에서 센터·교재를 선택합니다.
  3. 쪽 범위를 지정하고 범위 적용을 누릅니다. 단원을 열어 문항을 선택하거나 전체 선택을 누릅니다.
  4. 시험 이름을 80자 이내로 입력합니다. 제출기한 · 클리닉 설정에서 현재 시각으로 표시된 기한을 확인하고 필요하면 바꿉니다. 난이도는 그대로 / 더 쉽게, 문항 수는 1~3배에서 선택하고 이전 클리닉 문항 제외 여부를 정합니다. 알림 발송은 아니오입니다.
  5. 시험지 만들기를 누릅니다. 미리보기에서 출력 제목을 확인하고, 제목을 바꿨다면 제목 저장을 누릅니다. 1단 / 2단과 정답·해설 포함을 선택해 PDF 다운로드를 누릅니다.

2. 수업 테스트에 연결하고 학생 배정하기

  1. 담당 반의 수업추가 또는 수업 기록 수정에서 이번 수업 테스트 → 미탐존 시험지를 누르고 만든 시험지를 선택합니다. 기존 테스트에는 미탐존 연결을 사용합니다.
  2. 시험 이름과 수업 날짜를 확인하고 저장·정오 입력을 누릅니다. 수업 기록을 먼저 저장한 뒤 정오 입력을 엽니다.
  3. 시험 배정이 열리면 엠스위치 반을 선택합니다. 학생별 연결을 확인하고, 동명이인은 원생번호를 보고 맞춥니다. 배정할 학생만 선택하고 기한·설정을 확인한 뒤 선택 학생 배정을 누릅니다.

3. 정오 입력과 클리닉 PDF

  1. 학생 이름을 누르고 각 문항의 ○ / ×를 선택합니다. 전체 정답 / 전체 오답은 현재 학생에게, 선택 학생 전체 정답은 체크된 학생 모두에게 적용됩니다.
  2. 선택한 학생의 모든 문항을 입력한 뒤 채점 저장을 누릅니다. 엠스위치 채점 결과가 성적으로 반영됩니다.
  3. 반영된 점수칸은 회색으로 표시됩니다. 점수를 바꿀 때는 정오 입력을 수정하고 다시 채점 저장을 누릅니다.
  4. 채점된 학생을 선택하고 클리닉 PDF를 누릅니다. 한 명은 PDF, 여러 명은 ZIP으로 다운로드됩니다.

4. 지난 시험과 클리닉 다시 출력하기

  1. 미탐존 시험지 관리에서 시험지·교재 이름으로 검색합니다. 제목 수정으로 출력 제목을 바꾸거나 시험지 PDF로 다시 출력합니다.
  2. 응시 학생 · 클리닉에서 응시 강좌·날짜를 선택하고 학생별 채점 점수를 확인합니다.
  3. 출력할 학생을 체크한 뒤 1단 / 2단과 정답·해설을 선택하고 클리닉 PDF를 누릅니다. PDF 보관됨은 저장된 클리닉을 다시 출력합니다.

13 · 자료 준비

수업자료·시험지 관리

강좌관리 → 수업 데이터 관리

  1. 시험지 관리 또는 수업자료관리를 엽니다. 개인·공용과 사용할 소속을 선택합니다.
  2. 링크를 등록하거나 다중 등록에서 공개 구글드라이브 폴더를 불러옵니다. 공개 자료명을 비우면 파일명이 사용됩니다.
  3. 폴더를 만들고 자료를 끌어 옮기거나 여러 자료를 체크해 이동합니다. 검색 결과의 폴더 경로로 위치를 확인합니다.
  4. 수업 작성 화면의 저장한 자료 불러오기에서 여러 자료를 체크해 추가합니다.
  5. 수업에 들어간 자료의 제목과 순서를 확인하고 저장합니다.

파일을 직접 올릴 때

파일 올리기를 누르거나 파일을 끌어 놓습니다. 등록자 기준 1GiB까지 사용할 수 있으며, 남은 용량과 다운로드 기한을 확인하세요. 새 직접 업로드 파일은 30일이 지난 다음 새벽 2시에 정리됩니다. 기존 파일은 표시된 기한을 따르며 구글드라이브 링크에는 자체 기한이 없습니다.

서버 파일을 삭제하면 연결된 수업에서도 열 수 없습니다. 삭제가 완료되면 사용량이 줄어듭니다. 오래 쓸 원본은 별도로 보관하세요.

영상 공개와 시청 확인

수업 기록 → 수업 영상

  1. 영상 칸을 추가하고 유튜브 링크·제목을 입력합니다.
  2. 영상의 공개범위에서 강좌 설정을 따르거나 커스텀으로 학부모·학생 대상을 선택합니다.
  3. 수업을 저장하고 영상이 열리는지 확인합니다.
  4. 수업 영상 → 시청 현황에서 학생별 시청시간과 완료율을 확인합니다.
시청시간에는 반복 재생이 포함될 수 있습니다. 완료율은 서로 다른 구간을 얼마나 재생했는지 보여 줍니다.

배속 허용

강좌 정보 수정 → 동영상 배속에서 허용 여부와 최대 속도를 정합니다. 허용된 범위 안에서 영상이 지원하는 속도만 표시됩니다.

15 · 수업 준비

쌍둥이반 사용

담당 강좌의 쌍둥이반 설정

  1. 본인이 담당하는 반 중 함께 운영할 반을 연결합니다.

16 · 학생 확인

종합검색·리포트·지필평가

학생관리 → 학생종합검색 / 학생 리포트 / 지필평가 입력

학생종합검색

  1. 학생 이름·학교로 검색하고 학교·학년·원생번호를 확인합니다.
  2. 기간별 출결과 지난 보충·진행 중 보충·예정 보충, 강의실을 확인합니다.
  3. 반을 선택하여 최근 성적의 흐름을 확인합니다.

학생 리포트

학생을 선택해 학생·학부모에게 공개된 수업·공지·영상·코멘트와 출결·최근 성적을 상담 전에 확인합니다. 공개범위에 따라 학생과 학부모에게 보이는 내용은 다를 수 있습니다.

지필평가 입력

학교 중간·기말 성적은 지필평가 입력에서 학생·학교·학년·학기·시험을 확인하여 저장합니다. 클래스룸 수업 테스트와 구분해 입력하세요.

17 · 상담·협업

상담과 받은 업무 처리

학부모 상담 신청 / 타임넷 상담 기록 / 업무공유

학부모 상담 신청

학부모의 요청을 열어 학생·내용을 확인하고 답변과 처리 상태를 저장합니다.

타임넷 상담 기록

PC에서 반·학생을 검색해 상담 내용을 확인하고 입력합니다. 개인 타임넷 계정 연결이 필요합니다. 모바일에서는 제공되지 않습니다.

받은 업무

  1. 업무공유 → 받은 업무에서 업무를 열어 내용·관련 학생과 반·완료 기한을 확인합니다.
  2. 업무에 표시되는 확인 또는 수락 / 거절을 선택합니다.
  3. 수락 후 완료해야 하는 업무는 처리한 뒤 완료를 누릅니다.
  4. 지난 업무는 완료 / 전체 또는 학생·반 업무검색에서 찾습니다.
학생·반 태그를 누르면 관련 업무를 찾아볼 수 있습니다. 검색 시 동명이인의 학교·학년을 함께 확인하세요.

18 · 학생 이동

반 이동과 퇴원공유

학생관리 → 학생이동 / 퇴원공유

반 이동

  1. 학생이동에서 출발 반·학생·도착 반·이동일·받는 강사를 확인합니다.
  2. 요청을 보내고 상대방의 확인 상태를 봅니다.
  3. 처리 후 수강반과 출석부의 전출·전입 상태를 확인합니다.

  2. 공유 후 승인 진행 상태를 확인합니다.
  3. 잘못 요청했거나 취소가 필요하면 현재 처리 상태를 확인하고 담당자에게 요청합니다.
출석부의 상태만 바꿔 이동이나 퇴원을 대신 처리하지 않습니다.

19 · 직접 안내

담당 학생에게 앱 알림 보내기

공통관리 → 앱푸시 보내기 → 발송

  1. 사람으로 보기에서 학생을 찾거나 반으로 보기에서 반을 선택합니다.
  2. 받는 학생과 발송 가능 인원을 확인합니다. 알림을 받을 기기가 없는 대상은 제외됩니다.
  3. 제목·내용을 적고 알림 미리보기에서 확인합니다.
  4. 앱푸시 보내기를 누르고 결과를 확인합니다. 이전 결과는 발송 기록에서 찾습니다.
학부모에게 수업 내용을 알릴 때는 수업의 레포트 발송이나 출결 안내 기능에서 대상을 확인해 발송하세요.

20 · 발송 확인

알림·통신내역·로그인 이력

공통관리 → 통신내역 / 알림 수신 상태 / 로그인 이력

  1. 통신내역에서 담당 학생에게 보낸 안내를 찾습니다.
  2. 자세히를 열어 각 대상의 발송 시각·상태·실패 이유를 확인합니다.
  3. 알림 수신 상태에서 앱 설치와 알림 준비 상태를 확인합니다.
  4. 로그인 이력에서 담당 학생·학부모의 접속을 역할·이름·기간으로 찾습니다.
접수는 전송 요청이 접수된 상태이고, 기기 도착 확인은 기기가 알림을 받은 상태입니다. 학부모가 읽었다는 뜻은 아닙니다. 결과가 불분명하면 재발송 전에 이 화면을 확인하세요.

수업 전

  • 출결·진도·숙제·테스트 저장
  • 학생별 점수와 코멘트 확인

다른 기능 찾기

강좌리포트는 반별 운영 상태를, 강사자료실은 공용 자료를, 업데이트는 변경 소식을 확인할 때 사용합니다. 즉시 대화는 직원 메신저를 이용하세요.

오류가 보이면

작성 중인 내용과 화면의 오류 문구를 확인합니다. 저장·발송 여부가 불분명하면 기록부터 확인하세요. 계속 실패하면 발생 시각·반·수업 날짜·오류 문구를 담당자에게 전달합니다.
