처음 접속하면, 내 정보부터

  1. 클래스룸에 로그인하고 오른쪽 위의 내 이름 또는 개인설정을 엽니다.
  2. 내 전화번호를 저장합니다. 직원 연락처와 연락 안내를 확인할 때 사용합니다.
  3. 개인 타임넷 계정에 본인의 타임넷 아이디·비밀번호를 입력하고 연결 확인하고 저장을 누릅니다. 본인 이름으로 상담을 조회·입력할 때 필요합니다.
  4. 엠스위치 연동에 본인의 엠스위치 아이디·비밀번호를 넣고 저장 · 연동하기를 누릅니다. 담당 원생·학부모 연락처를 확인하고 번호를 맞출 때 사용합니다.

클래스룸 로그인 계정과 타임넷·엠스위치 계정은 서로 별개입니다. 비밀번호를 바꾸면 클래스룸에 저장한 연결 정보도 바꿔 주세요. 별도의 미래탐구 연결기는 설치하지 않습니다.

문자 발송은 관리자가 설정한 공용 엠스위치 계정을 사용합니다. 개인 계정 저장과 공용 발송 계정은 구분됩니다.

연결 확인

주의사항이 보이면 이렇게 해결하세요

위쪽 주의 N건에서 빠진 전화번호·계정 정보나 연락처 불일치를 확인합니다. 해결방법을 읽고 바로 이동으로 수정하세요.

  • 엠스위치 비밀번호 변경 필요: 엠스위치 사이트에 직접 로그인 → 비밀번호 변경 안내 완료 → 클래스룸 개인설정에 새 비밀번호 저장 → 저장 · 연동하기.
  • 엠스위치 본인 확인 필요: 엠스위치 사이트에서 본인 확인·로그인 제한 안내를 해결한 뒤 클래스룸에서 연결 재확인.
  • 타임넷 연결 확인 필요: 타임넷 직접 로그인 확인 → 클래스룸의 개인 타임넷 연결에서 계정 확인·저장.

빈 계정이나 해결되지 않은 연결 오류는 자동 로그인 시도를 멈춥니다. 오류가 계속되면 화면의 오류 코드와 발생 시각을 관리자에게 전달하세요. 임의로 여러 번 발송하지 말고 통신내역부터 확인합니다.

강좌 준비

강좌와 수업은 다릅니다

강좌는 학생들이 함께 수강하는 반 전체입니다. 예: 3MC3, BLACK H6. 수업은 그 반에서 하루 진행한 한 회차입니다. 예: 10월 30일 3회차.

  1. 강좌관리 → 강좌 설정에서 강좌를 추가합니다.
  2. 강좌명·과목·개강일·종강일·수업 요일·시작/종료 시각을 입력합니다.
  3. 체크한 요일마다 강의실을 숫자 3자리로 지정합니다. 요일별로 다른 강의실을 사용할 수 있습니다.
  4. 담당강사와 필요한 설정을 확인하고 저장합니다. 담당강사 교체는 권한이 있는 직원만 할 수 있습니다.

강좌 목록에서 반을 누르면 설정과 수업 기록이 펼쳐집니다. 강좌 정보 수정은 반의 일정·정보, 강의계획은 회차별 계획, 공개범위는 학생·학부모에게 보이는 항목을 설정합니다.

강좌 설정

공개범위와 쌍둥이반

공개범위에서 학생·학부모에게 보여 줄 수업 내용·성적·자료 등의 범위를 확인합니다. 수업 기록의 공개 여부와 개별 항목 설정에 따라 실제 가족 화면이 달라집니다.

쌍둥이반은 본인이 담당하는 반끼리 연결합니다. 연결된 회차의 수업 제목·진도·숙제·공지·테스트·영상·추가자료 등을 함께 사용합니다. 전체 회차 수가 다르면 대응할 날짜를 선택합니다. 각 반의 강의실·학생·출결은 별개입니다. 시험은 다른 반에 복사되어도 그 반의 학생 점수가 자동으로 입력되지는 않습니다.

쌍둥이 시험의 평균·상대적 위치는 연결된 반의 응시 성적을 함께 반영합니다. 수업 기록 평가도 연결 회차를 기준으로 집계합니다. 학생별 출결과 코멘트 입력률 등은 반마다 다를 수 있습니다. 연결 수업 삭제는 쌍둥이반에도 영향을 주므로 삭제 창의 대상을 확인하세요.

학생 등록

강좌에 학생을 등록합니다

  1. 학생관리 → 학생 관리에서 학생관리 버튼을 열고 등록할 강좌를 선택합니다.
  2. 타임넷 명단에서 학생을 찾습니다. 학생명뿐 아니라 학교·학년·원생번호를 함께 확인합니다.
  3. 필요하면 타임넷 학생 불러오기로 명단을 갱신합니다. 타임넷에 등록되지 않은 학생은 타임넷 불러오기 명단에서도 찾을 수 없습니다.
  4. 아이디·학부모 연결·등록할 수강반을 확인한 뒤 저장합니다.
타임넷 원생 명단은 공용으로 활용합니다. 매번 새로 불러오기 전에 화면의 최근 갱신 시각을 확인하세요. 오늘과 한 달 뒤 기준에서 조회된 명단을 중복 없이 합쳐 개강 예정 학생도 확인합니다. 원본 시스템의 조회 권한·등록 상태에 따라 검색 결과는 달라질 수 있습니다.

명단 갱신은 원본 정보를 읽는 작업이고, 클래스룸 강좌에 학생을 등록하는 작업은 따로입니다. 이름만 같다고 같은 학생으로 판단하지 마세요.

학생·학부모 계정

아이디와 초기 비밀번호를 확인하세요

학부모 계정 자동 생성과 기본 비밀번호 사용하기는 기본 체크 상태입니다. 자동 발급 대신 직접 설정할 수도 있습니다.

  • 이미 발급된 학생: 과거 수강생이거나 다른 반도 함께 듣는 병강생일 수 있습니다. 같은 원생으로 확인되면 기존 계정을 사용합니다. 기존 비밀번호를 새 초기 비밀번호로 바꾸지 않습니다.
  • 서로 다른 동명이인: 사용 중인 아이디와 겹치지 않도록 이름 뒤에 숫자가 붙습니다. 예: 김주원, 김주원2. 안내할 때 끝의 숫자까지 꼭 확인합니다.
  • 확인 위치: 학생관리 → 학생 학부모 계정 관리. 발급 아이디와 학부모 연결 여부를 확인합니다.

새 계정의 기본 비밀번호를 사용한 경우 1234로 안내합니다. 이 비밀번호로 로그인하면 새 비밀번호를 두 번 입력해 변경해야 이용할 수 있습니다. 이미 본인이 변경한 비밀번호는 조회할 수 없으며, 앱설치 안내 문자에는 ‘본인이 설정한 비밀번호’로 표시됩니다.

학부모 연락처

전화번호를 먼저 맞춰 주세요

클래스룸·타임넷·엠스위치에 등록된 학부모 번호를 비교합니다. 서로 다른 번호가 보이거나 주의사항에 연락처 확인이 뜨면 실제 보호자 번호를 확인해야 합니다.

  1. 학생관리 → 학부모 전화번호 관리에서 해당 학생·학부모를 검색합니다.
  2. 현재 클래스룸 번호와 타임넷 참고 번호, 엠스위치 번호를 확인합니다. 엠스위치 정보가 오래되었다면 즉시 갱신을 누릅니다.
  3. 맞는 엠스위치 학생을 선택하고 올바른 번호를 입력한 뒤 저장 결과를 확인합니다.
  4. 여기서 해결되지 않으면 엠스위치에 직접 접속해 학생·학부모 연락처를 수정하고 클래스룸에서 다시 갱신합니다.

문자는 엠스위치 문자 시스템을 이용하므로 엠스위치 번호가 중요합니다. 클래스룸에서 지정한 연락처와 실제 발송 대상이 일치하는지 확인하세요. 앱푸시는 전화번호로 보내는 문자가 아니라, 해당 학생·학부모의 로그인 계정과 알림을 허용한 기기로 전달됩니다. 학부모 계정 연결도 정확해야 합니다.

앱설치 안내

학부모에게 설치 안내 문자를 보냅니다

  1. 공통관리 → 앱푸시 보내기 → 앱설치 알림 문자 발송으로 들어갑니다.
  2. 필요하면 엠스위치 명단을 갱신합니다. 담당 학생의 학부모 중 앱 알림이 아직 준비되지 않은 대상을 선택합니다. 앱 알림 가능 상태인 대상은 제외됩니다.
  3. 이름이나 행을 누르면 실제 메시지에 그 학부모의 아이디·비밀번호 안내가 반영됩니다. 체크한 대상과 메시지를 확인합니다.
  4. 발송 버튼을 누르고 결과를 확인합니다. 학생 문자 발송은 지원하지 않아 학부모만 표시합니다.

안내 문구는 수정할 수 있지만 <$아이디>와 <$비밀번호>는 반드시 남겨야 합니다. 학생·학부모의 계정과 연결된 기기가 맞는지 먼저 확인하세요.

★ 설치 안내 문자는 같은 학부모에게 너무 자주 보내지 마세요. 일주일에 한 번만 안내해 주세요. 이 안내는 운영 권장 주기이며 발송 횟수를 자동 차단하는 기능은 아닙니다.

수업 전

강의계획서를 작성합니다

  1. 강좌 설정에서 해당 반 → 강의계획을 엽니다.
  2. 수업 날짜·회차별로 진도와 계획을 입력합니다. 휴강일도 확인합니다.
  3. 저장 후 강의계획서 모아보기에서 다른 일정과 함께 확인합니다.

강의계획은 예정 내용입니다. 실제로 진행한 진도·숙제·학생별 기록은 아래의 수업 추가에서 저장합니다. 계획을 작성했다고 출결이나 성적을 입력한 것으로 처리되지는 않습니다.

수업 당일

등원할 때는 실시간 출결

  1. 출결관리 → 실시간 출결에서 반과 날짜를 확인합니다.
  2. 학생별로 등원 / 미등원 / 결석 / 지각을 누릅니다. 같은 버튼을 다시 누르면 선택이 해제됩니다.
  3. 모바일의 전체 출석은 표시된 학생의 등원을 일괄 선택하는 기능입니다. 누르는 즉시 안내를 보내지는 않습니다.
  4. 출석부 저장 후 학부모 안내 발송을 눌러 저장·안내를 진행합니다.

앱 알림을 받을 수 있는 학부모는 앱푸시를 우선 사용합니다. 문자 대상과 실제 처리 결과는 통신내역에서 확인하세요. 결과를 모를 때 발송 버튼을 계속 누르지 마세요.

출결 정리

출석부는 세 화면이 연결됩니다

실시간 출결 · 출석부 · 수업 기록의 학생별 출결은 같은 날짜와 강좌의 기록을 사용합니다. 출석부에 먼저 입력했다면 수업 기록을 열 때 해당 값이 보이며, 수업 기록에서 저장한 출결도 출석부에 반영됩니다.

  1. 출결관리 → 출석부에서 반과 조회 기간을 선택합니다.
  2. 날짜별 출결을 확인하고 필요한 결석 사유 등을 적어 저장합니다.
  3. 학생 한 명의 여러 반 출결은 학생관리 → 학생종합검색에서 확인합니다.

전입·전출·퇴원은 학생 이동·퇴원 처리에서 자동 반영되는 상태입니다. 출석부에서 임의로 직접 지정하지 않습니다. 다른 강사의 출석부는 부여된 조회·수정 권한에 따라 이용할 수 있습니다.

출석부의 조회 범위에서 이번 달 수업을 선택하면 이번 달 수업만 보고 출력할 수 있습니다. 범위를 바꿀 때마다 계정에 저장되어 다음 접속에도 같은 선택으로 열립니다. ‘이번 달 수업’은 달이 바뀌면 새 달을 따라가고, 특정 월·직접 지정한 기간은 선택한 값을 유지합니다.

수업 기록

수업을 마치면 한 회차를 저장합니다

  1. 강좌관리 → 강좌 설정 → 해당 반에서 수업 추가를 누릅니다.
  2. 수업일·회차·제목, 오늘의 진도, 숙제 안내, 필요한 공지를 입력합니다. 이미 등록된 회차는 새로 추가하지 말고 기존 기록을 수정합니다.
  3. 추가자료·영상·테스트를 등록하고 학생별 출결·과제·코멘트를 확인합니다. 온라인 과제 제출 허용은 기본 해제이며 필요할 때 체크합니다.
  4. 저장으로 기록만 저장하거나 레포트 발송으로 안내할 대상을 선택합니다.

레포트 발송 창은 학부모와 학생을 나누어 보여 줍니다. 날짜별 출결 상태를 확인하고 체크된 대상만 발송하세요. 결석했다고 항상 자동 제외되는 것으로 생각하지 말고 체크 상태를 확인합니다.

수정 화면 하단의 삭제로 잘못 만든 수업을 지울 수 있습니다. 쌍둥이반에 연결된 대응 수업도 함께 삭제될 수 있으므로 확인창을 읽습니다.

시험지·수업자료

자료는 한 번 저장해 여러 수업에

강좌관리 → 수업 데이터 관리에서 시험지 관리 / 수업자료관리를 선택합니다. 개인 자료와 공용 자료를 구분합니다. 공용은 지정한 과목에서 공유되며 작성자·등록일이 표시됩니다.

  1. 제목과 자료 링크를 등록합니다. 수업자료는 PDF·사진·한글 파일 등의 구글드라이브 링크를 사용할 수 있습니다.
  2. 구글드라이브는 학생·학부모가 볼 수 있도록 링크가 있는 모든 사용자 · 뷰어로 공유합니다. 파일 형식에 따라 바로 미리보기가 되거나 내려받아 열 수 있습니다.
  3. 왼쪽에서 폴더를 선택한 뒤 새 폴더를 누르면 그 안에 하위 폴더를 만들 수 있습니다. 화살표로 하위 폴더를 펼치고 접습니다. 오른쪽 파일이나 왼쪽 폴더를 원하는 폴더로 끌어 옮깁니다. 여러 파일에 체크한 뒤 한 번에 이동할 수도 있습니다. 자료는 한 줄씩 표시하며, 오른쪽 ⋯에서 전체 이름·경로·등록자·기한과 수정·삭제·이동을 확인합니다. 모바일은 폴더 버튼으로 폴더 목록을 엽니다. 폴더를 지정하지 않은 기존 자료는 바탕화면에 남습니다. 이 폴더는 구글드라이브 원본 폴더를 변경하지 않습니다.
  4. 여러 파일은 다중 등록에서 공개 구글드라이브 폴더 링크를 넣어 불러옵니다. 공개 자료명을 비우면 파일명을 사용합니다. 이미 등록된 링크는 제외됩니다.

수업 추가에서 저장한 자료 불러오기를 열면 개인·공용 자료를 검색하고 체크하여 한 번에 추가할 수 있습니다. 검색 결과에는 폴더도 표시됩니다. 일회성 링크도 입력할 수 있고 위·아래 화살표로 자료 순서를 바꿀 수 있습니다. 시험지 선택에서는 개인·공용 체크 범위를 확인합니다.

자료 보관

파일을 직접 올릴 수도 있습니다

수업자료관리의 파일 올리기를 누르거나 파일을 끌어 놓아 서버에 등록할 수 있습니다. 수업에 연결하면 공개범위에 맞는 학생·학부모가 자료를 열 수 있습니다. 사진·한글 문서도 자료로 제공할 수 있으며, 한글 문서는 휴대폰에 뷰어가 필요할 수 있습니다.

서버에 직접 올린 파일은 30일이 지난 뒤 처음 오는 새벽 2시에 삭제하며 다운로드 기한과 작성자·등록일이 자료 옆에 표시됩니다. 업데이트 전 올린 파일은 원래 기한을 유지합니다. 구글드라이브 링크는 기한 무제한으로 표시됩니다.

강사 1명당 서버 자료 1 GB(1,024 MB)까지 저장할 수 있습니다. 개인·공용 시험지와 수업자료를 등록자 기준으로 합산하며, 자료관리 상단의 게이지와 숫자로 확인합니다. 업로드 중인 용량도 포함하고 구글드라이브 링크는 제외합니다. 만료 파일이 실제 삭제되면 사용량이 줄어듭니다. 기존 자료가 1 GB를 넘더라도 삭제하지 않고 새 업로드만 제한합니다.

장기간 사용할 자료는 원본을 별도로 보관하고, 기한을 확인해 다시 등록하거나 구글드라이브 링크를 사용하세요. 자료 목록에서 삭제하면 원본 제공 상태도 달라질 수 있으니 연결된 수업을 확인합니다.

영상 등록

수업 영상과 시청 현황

  1. 수업 기록의 영상 칸을 추가하고 유튜브 영상 링크·제목을 입력합니다.
  2. 영상 옆 공개범위에서 강좌 설정에 따름 또는 커스텀을 선택합니다.
  3. 커스텀에서는 학부모·학생을 나눈 목록에서 보여 줄 대상만 체크합니다.
  4. 저장 후 해당 수업의 영상 관리·시청 현황에서 학생별 재생 진행 상태를 확인합니다.

가족은 클래스룸 안의 재생 화면에서 영상을 봅니다. 기본 화면에서 유튜브로 나가는 직접 이동 요소를 제한합니다. 수업 상세의 수업 영상 → 시청 현황을 열면 학생·영상별 시청 시간과 완료율을 볼 수 있습니다. 시청 시간에는 같은 부분을 반복해서 본 시간이 포함됩니다. 완료율은 영상 전체에서 중복 없이 재생한 구간의 비율이며, 건너뛴 구간은 제외됩니다. 학생 이름 검색·영상 선택·완료율 또는 시청 시간 정렬로 확인할 대상을 찾습니다. 학생 계정으로 클래스룸에서 재생한 기록을 집계하며 학부모·강사의 미리보기는 제외합니다. 이 기록이 실제 이해도나 집중도를 뜻하지는 않습니다.

평가 입력

시험 성적과 지필평가 성적

수업의 테스트에 시험 제목·만점을 정하고 학생별 점수를 입력합니다. 만점보다 높은 점수는 저장할 수 없습니다. 미응시와 미입력을 구분하고 실제로 응시한 시험만 점수를 넣으세요.

학생관리 → 지필평가 입력에서는 학교의 중간·기말 등 지필평가 성적을 등록합니다. 학생·학교·학년·학기·시험 종류가 맞는지 확인합니다. 수업 테스트 점수와 학교 지필평가 성적은 구분해 관리합니다.

쌍둥이 시험은 시험 정의가 공유되지만 학생별 성적은 각 반에서 입력합니다. 학습 리포트와 성적 흐름에서 입력 결과를 확인하세요.

리포트·종합검색

상담 전에 학생의 화면을 확인합니다

학생관리 → 학생 리포트에서 이름·학교를 입력하고 학생을 선택합니다. 학생·학부모에게 공개된 수업 내용·출결·성적·공지·영상·코멘트를 간접 확인해 상담 자료로 사용합니다. 학생·학부모의 공개범위가 다르면 실제로 볼 수 있는 항목도 다를 수 있습니다.

학생종합검색은 직원 상담용 화면입니다. 왼쪽에서 기간별 출결을, 오른쪽에서 지난 보충 최근 3건 / 지금 진행 중 / 예정 보충과 강의실을 확인합니다. 시험 성적은 수강반을 선택하여 최근 흐름을 봅니다. 이름이 같으면 학교·학년·원생번호로 구분합니다.

학습 리포트는 출결·성적·과제 등의 학습 상태를, 강좌리포트는 반별 운영 상태를, 권한이 있는 직원의 강사 입력 현황은 기록 입력 상태를 확인하는 화면입니다.

보충 관리

보충을 지정하고, 필요할 때만 안내

  1. 보충 관리에서 대상 학생·반·사유·준비물·시간·강의실을 입력합니다. 새 보충은 3자리 강의실 필수입니다.
  2. 직접 날짜를 정해 지정하거나 신청 가능한 시간을 열어 학생·학부모가 선택하게 합니다. 지난 보충도 실제 진행 날짜로 등록할 수 있습니다.
  3. 저장 후 목록을 확인합니다. 등록만으로 학부모에게 알림을 보내지 않습니다.
  4. 안내가 필요할 때 해당 보충의 앱푸시 알림 버튼을 누릅니다. 잠시 나타나는 접수·결과 안내를 확인하세요.

나중에 다시 안내할 수도 있습니다. 연속 클릭은 잠시 차단되므로 기다렸다가 통신내역을 확인합니다. 종료 시각이 지나면 지난 보충으로 분류됩니다. 이전 보충에 강의실이 없으면 ‘—’로 표시합니다. 보충 취합에서는 허용된 범위의 강사별 현황을 확인합니다.

학생 이동

전반·전출과 퇴원

학생관리 → 학생이동에서 학생의 전반·전출을 요청합니다. 출발 반·학생·도착 반·이동일과 받는 강사를 확인하고, 상대방이 확인하는 흐름에 따라 처리합니다. 수강 정보와 출석부의 전출·전입 표시는 함께 연결됩니다.

퇴원은 같은 학생관리 영역의 퇴원공유에서 학생·반·최종 수업일·사유를 입력하고 정해진 승인라인으로 보냅니다. 승인자는 내용을 확인하여 승인 또는 반려합니다. 출석부에서 직접 퇴원 상태를 찍는 방식은 사용하지 않습니다.

잘못 처리한 퇴원은 권한이 있는 직원이 퇴원취소에서 관련 수강·출결 변경을 확인한 뒤 처리합니다. 이동·퇴원 뒤 다른 기록이 바뀐 경우 자동 취소가 제한될 수 있습니다.

상담실 근무자

상담실의 퇴원 마무리

승인이 모두 끝나면 상담실 근무자로 지정된 모든 활성 직원에게 앱푸시를 요청합니다. 근무표의 현재 근무 시간만으로 대상을 제한하지 않습니다. 기기에서 앱 알림을 허용해야 실제로 받을 수 있습니다.

  1. 학생관리 → 퇴원처리에서 누적 기록을 찾습니다.
  2. 처리 내역을 열어 공유자·사유·승인자·시각을 확인합니다.
  3. 타임넷에서 해당 반의 퇴원을 실제로 처리합니다.
  4. 클래스룸으로 돌아와 타임넷 퇴원 처리 완료를 누릅니다. 누른 사람과 시각이 남습니다.
이 버튼은 타임넷을 대신 조작하지 않습니다. 타임넷에서 끝낸 작업을 기록하는 버튼입니다.

상담실 근무자 지정은 기존 상담실 관리에서 합니다. 별도의 ‘수업을 하지 않는 사람’ 체크는 없어졌습니다. 지정된 직원은 ‘내 수업만 보기’가 숨겨지고 해제된 상태로 동작하며 학생종합검색에서는 과목과 관계없이 조회할 수 있습니다. 수정 권한은 기존 권한 설정을 따릅니다.

직원 협업

학생과 반을 연결해 업무를 공유합니다

  1. 업무공유 → 업무 공유를 열고 내용을 적습니다.
  2. 내용 옆 학생·반 추가로 학생이나 반을 검색합니다. 학생은 학교·학년·원생번호를 확인하여 선택합니다.
  3. 붙은 태그를 확인하고 받는 직원, 확인만/수락·거절/완료 등의 처리 방식을 정해 공유합니다.
  4. 받는 직원이 확인하면 보낸 직원의 업무 화면도 수 초 간격으로 변경 여부를 확인해 갱신합니다. 다른 화면을 보거나 창이 숨겨져 있으면 불필요한 조회를 줄입니다.

학생·반 업무검색에서 태그를 선택하면 해당 학생·반으로 오간 업무와 발신자·수신자·응답·시각을 확인할 수 있습니다. 일반 직원은 본인이 보낸 업무와 받은 업무만 검색합니다. 상담실 근무자는 본인이 참여하지 않은 업무도 검색할 수 있습니다.

즉시 대화는 직원 메신저, 공용 파일·안내는 강사자료실, 변경 소식은 업데이트 게시판을 이용합니다.

발송·접속 기록

안내가 제대로 갔는지 확인하세요

공통관리 → 통신내역에서 본인 학생에게 보낸 문자·앱푸시 결과를 확인합니다. 수업 레포트나 실시간 출결은 관련 수업 단위로 묶입니다. 자세히에서 대상별 시각과 결과를 확인하세요.

‘요청 접수’, ‘발송 결과’, ‘기기 수신’은 서로 다른 단계입니다. 접수됐다는 표시만으로 학부모가 읽었다고 판단하지 마세요. 확인이 필요한 결과는 오류 코드를 함께 봅니다.

알림 수신 상태에서 설치·알림 준비 상태를, 로그인 이력에서 담당 학생·학부모의 접속 여부를 확인합니다. 조회 권한이 넓은 직원은 허용된 전체 범위를 볼 수 있습니다. 이름·역할·날짜 조건을 이용하세요.

타임넷 상담 기록
PC에서 반·학생을 찾아 원본 타임넷 상담 내용을 확인하고 입력합니다. 모바일에서는 제공하지 않습니다.
입학 테스트
등록된 입학 테스트와 응시·처리 결과를 권한에 맞게 관리합니다.
문자보내기 / 앱푸시 보내기
대상과 내용을 확인한 뒤 직접 발송합니다. 대상 선택과 최종 확인은 따로 확인하세요.
학교 로그인
권한이 있는 직원이 등록된 학교 관련 접속 정보를 이용합니다.
상담실근무표 / 퇴원 승인라인 / 퇴원취합
권한이 있는 직원이 근무 배치, 과목별 승인 순서, 퇴원 현황을 관리합니다.
강사 권한 / 직급 권한
관리자가 직원 계정·과목·직급·조회 및 수정 권한을 설정합니다.
활동 기록 / 로그인 화면 / 상세 설정
권한이 있는 관리자가 변경 이력, 화면 구성, 공통 안내 문구 등을 관리합니다.
서버 : 양호·주의·위험
클래스룸의 연결·처리 상태를 확인합니다. 오류가 있으면 시각·작업·코드를 관리자에게 전달합니다.

메뉴는 계정과 권한에 따라 다릅니다. 필요한 메뉴가 없으면 관리자에게 담당 업무와 필요한 조회·수정 범위를 알려 주세요.
